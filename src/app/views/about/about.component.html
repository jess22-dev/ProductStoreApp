Acerca de la Aplicación

Esta aplicación es una tienda en línea desarrollada con Angular. Su propósito es proporcionar una interfaz amigable y moderna para visualizar productos, ver sus detalles y agregarlos al carrito de compras.

Se utilizan componentes de Angular Material para lograr un diseño limpio y responsivo. Entre las tecnologías empleadas se encuentran:

  • Angular 16
  • Angular Material
  • TypeScript
  • CSS moderno con flexbox y diseño responsivo

La aplicación está pensada como una base sólida para proyectos de comercio electrónico o demostraciones educativas.
